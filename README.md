# Vince Création

Site vitrine statique en HTML, CSS et JavaScript, prêt à publier avec GitHub Pages.

## Fichiers

- `index.html` : contenu et structure du site
- `style.css` : identité visuelle et mise en page responsive
- `script.js` : menu mobile et année automatique du pied de page

## Publication avec GitHub Pages

1. Crée un dépôt GitHub et ajoute ces trois fichiers à sa branche `main`.
2. Ouvre **Settings → Pages** dans le dépôt.
3. Choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
4. Enregistre. GitHub Pages indiquera l’adresse publiée dans cette même page.

## À personnaliser avant publication

- Vérifier l’adresse `bonjour@vincecreation.fr` dans les liens de contact.
- Ajouter les coordonnées réelles, les mentions légales et la politique de confidentialité si nécessaire.
- Confirmer les prestations et tarifs affichés, ainsi que les modalités exactes de maintenance.
- La section Atelier Augustin est une maquette fictive de démonstration, pas une réalisation client.

Le projet n'inclut pas de formulaire connecté, de système de réservation, ni d'hébergement ou de nom de domaine.
